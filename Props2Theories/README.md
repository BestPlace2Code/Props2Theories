# Props2Theories NameSpace

Opening this folder, you opened `Props2Theories` namespace with all the course structure

Here, you can see the `TacticNames.lean` and `Axioms.lean` files, as well as all the folders with different math subject.
The first letter in the name of the subject (before the underscore `_` symbol) gives you the correct order of the chapters to study.

You can start with the first (`A`) subject - `Logic` and go on.
